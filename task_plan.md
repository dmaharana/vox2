# Task Plan: Slash Autocomplete for Skills, Tools & Commands

## Goal

1. All available skills (e.g. `/<skill_name>`).
2. All available tools (e.g. `/<tool_name>`).
3. Built-in system slash commands (`/skills`, `/tools`, `/help`).
